# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Директория cmd/ содержит точку входа main.go, которая инициализирует базу данных и запускает веб-сервер.

Директория pkg/db/ отвечает за работу с базой данных: подключение, инициализация схемы, добавление, получение, изменение и удаление задач.

Директория pkg/api/ содержит обработчики HTTP-запросов для работы с задачами и вспомогательные функции.

Директория pkg/server/ реализует запуск веб-сервера, маршрутизацию и подключение API.
